# Pocket Quiet icon

Generated using the built-in image generation tool (not the API/CLI fallback).

The mint fan and dark teal badge match the application's existing palette. The source PNG has a transparent background. Mechanical format conversion preserves its artwork and alpha, and produces ten Windows ICO sizes for different DPI settings.

- Source: `src/PocketQuiet.App/Assets/PocketQuiet.png`
- Windows icon: `src/PocketQuiet.App/Assets/PocketQuiet.ico`
- Conversion: `scripts/Build-Icons.ps1`
- Applied to: executable, window/title bar, taskbar, desktop shortcut, sidebar, and system tray.

## Generation prompt

Use case: logo-brand. Asset: production Windows application icon for Pocket Quiet, a quiet adaptive laptop fan controller. Create ONE square icon centered on a truly transparent background. A clean solid deep charcoal-teal circular badge (#13282E), containing a bold mint green (#8EE3B0) three-blade cooling fan symbol with a small round center hub. Smooth rounded geometric blades, simple distinct negative-space gaps, calm balanced rotational symmetry. Flat vector-like rendering, crisp silhouette, high contrast, minimal detail. The badge fills about 90% of the canvas, with transparent margins. Must remain recognizable at 16x16 system-tray size and on both light and dark Windows taskbars. No letters, no words, no extra graphics, no thin strokes, no outer shadows, no gradients, no textures, no mockup. Output a single finished icon, not an icon sheet.

Pocket Quiet 사용설명서

버전 0.2.0 · Windows x64 · GPD Pocket 4용 초기 공개판

설치와 업데이트

전체 ZIP을 압축 해제하고 Install.cmd를 실행합니다. 화면 앱과 서비스는 관리자 권한이 필요합니다. 다른 팬 제어 도구는 종료하세요. 설치기는 배포 파일의 SHA-256, PawnIO 설치 파일 서명, 서비스 응답을 확인합니다. 기존 서비스는 중지 후 교체되며 이전 서비스 폴더는 Program Files의 Pocket Quiet.previous-시각에 남습니다. 새 서비스의 준비 상태 확인이 실패하면 이전 서비스 복원을 시도합니다.

서비스는 C:\Program Files\Pocket Quiet에서, 화면 앱은 압축 해제한 폴더에서 실행됩니다. 배포 폴더의 service 파일만 교체하면 설치된 서비스는 바뀌지 않습니다. 화면 앱은 완전히 종료한 후 새 배포 파일을 교체하세요. PocketQuiet.exe만 따로 옮기지 마세요.

수동 제어와 EC 접근은 GPD G1628-04 / G1628-04-L, BIOS 정확히 2.11에서만 허용합니다. -L은 프로토콜 매핑만 확인했고 실물 시험은 하지 않았습니다. 다른 모델/BIOS에서는 EC를 읽거나 쓰지 않고 가능한 CPU/GPU 센서만 표시합니다.

부팅·서비스 재시작·절전 복귀 후에는 기기 기본 자동으로 시작합니다. 이전 수동 프리셋을 자동 재적용하지 않습니다.

프리셋

  • 기기 기본 자동: EC 자동값 쓰기와 읽기 확인 후 펌웨어에 제어를 돌려줍니다.
  • 무소음 · 최소 소음: 저온에서 가능한 낮은 출력을 유지합니다. 팬 정지나 0dB는 보장하지 않습니다.
  • 저소음: 가벼운 작업에서 낮은 출력, 온도 상승 시 점진 가속.
  • AI 자동 · 적응형: 온도 평균·상승 속도·선호도를 사용하는 로컬 규칙 기반 제어입니다. 학습 모델이나 인터넷 API를 쓰지 않습니다.
  • 균형: 온도와 소음의 균형.
  • 냉각 우선: 낮은 온도부터 상대적으로 높은 출력.
  • 사용자 지정: 2~12개 점을 편집하고 미리보기 그래프로 확인.

냉각 우선은 35°C/45%, 50°C/60%, 65°C/75%, 75°C/90%, 85°C/100%입니다. 점 사이를 선형 보간하며 실제 출력에는 보호·평균·감속 지연이 적용됩니다.

사용자 곡선은 온도 20~85°C, 출력 30~100% 범위입니다. 온도는 엄격하게 증가하고 출력은 감소하면 안 됩니다. 마지막 점은 85°C/100%입니다. 잘못 입력한 칸은 색으로, 점 사이 관계 오류는 문구로 알립니다. 프리셋과 선호도는 프리셋 적용을 눌러 반영합니다.

보호와 소음

평균 시정수는 약 4초, 평상시 상승 한도는 초당 12%포인트입니다. 충분한 감속 조건이 20초 유지되면 초당 최대 1.5%포인트씩 내려갑니다. 설정 재적용 시 출력·감속 상태를 유지합니다. 처음 수동 전환할 때도 최근 온도가 55°C 이하이고 팬이 회전 중이면 곡선 출력으로 시작합니다. 그 외에는 초기 60%와 고온 보호를 사용합니다.

0.2.0에서는 75°C 이상 최소 65%, 80°C 이상 최소 90%를 실제 요청 출력에 즉시 적용합니다. 85°C 이상은 유효 센서 데이터에서 즉시 100%입니다. 센서 오류 또는 RPM 0 연속 5회는 수동 제어 중단과 자동 복귀를 시도하며, RPM 0 연속 2회부터는 최대 출력으로 회전을 재시도합니다.

무소음 모드도 고온 보호를 따릅니다. 80~85°C에서 큰 바람 소리가 지속되면 소음 줄이기 안내와 전력 효율 설정을 확인하세요. 전력 설정은 사용자가 Windows에서 직접 변경하며 앱이 TDP·전압·CPU 부스트를 임의 변경하지 않습니다. 소음 개선 안내에 원인과 ANC 검토가 있습니다.

서비스 신호가 약 8초 끊기면 watchdog은 서비스 종료·자동 복귀를 시도하고 Windows 서비스 관리자가 재시작합니다. 감시 프로세스가 사라지면 서비스는 수동 제어를 해제하고 감시 프로세스 재시작을 시도합니다. OS 전체 정지, 커널 드라이버 정지, 하드웨어 고장에 대한 복귀 보장은 아닙니다.

종료·복구·진단

X는 트레이로 숨깁니다. 숨겨진 화면은 그래프 렌더링을 생략하고 5초마다 상태만 조회하며 서비스의 1초 제어는 계속됩니다. 새로 실행하면 기존 창을 엽니다. 자동 복귀 후 종료는 실제 복귀 확인 후 종료합니다. 화면 앱 강제 종료는 서비스 제어를 중지하지 않습니다.

연결 재초기화는 기존 수동 제어 해제를 확인하고 센서 객체를 재생성합니다. 실패 시 오류와 최근 보호 기록을 확인하세요. Recover.cmd는 서비스를 중지하고 자동 제어값을 검증하며, 성공 후에도 서비스는 중지 상태로 남습니다.

설정은 %ProgramData%\PocketQuiet\settings.json, 측정은 telemetry-날짜.csv, 오류는 errors.log, 독립 복구 기록은 watchdog.log입니다. UTC를 기록합니다. 측정 파일은 하루 약 20MB 상한·14일 보존, 오류는 약 2MB·이전 파일 하나, watchdog 로그는 약 1MB·이전 파일 하나입니다. 기록 실패나 큐 포화 시 일부 로그가 누락될 수 있습니다.

Uninstall.cmd는 서비스와 설치 파일, 바로가기를 제거합니다. 로그·이전 버전 백업·배포 폴더·공유 PawnIO는 남깁니다. 앱/서비스는 Authenticode 서명이 없으며 PawnIO 설치 파일의 서명과 구분해야 합니다.

--demo에서는 센서와 적용·초기화·재연결을 모두 가상 처리합니다. 실제 서비스에 요청하지 않습니다.

검증 범위

자동 정책·서비스 상태 테스트와 Windows 빌드, 화면 실행을 확인합니다. 버전별 실제 시험 결과는 VALIDATION.md를 참고하세요. 장시간 고부하·소음계 측정·실제 절전/최대 절전의 포괄 시험을 대신하지 않습니다.

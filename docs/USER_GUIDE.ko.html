Pocket Quiet 사용설명서

버전 0.1.0 · Windows x64 · 하드웨어 시험을 거친 초기 공개판

1. 프로그램이 하는 일

Pocket Quiet는 기기의 온도에 맞춰 팬 출력을 조절합니다. 가벼운 작업에서 불필요한 회전을 줄이고, 발열이 지속되면 팬을 높이며, 온도가 내려가면 천천히 감속합니다. 팬 출력을 줄이는 만큼 온도가 올라갈 수 있습니다. 지속적으로 높은 성능을 사용하는 작업에서 항상 조용해지는 것은 아닙니다.

지원하는 수동 제어 대상은 GPD Pocket 4의 모델 코드 G1628-04 및 G1628-04-L, BIOS 2.11입니다. 실제 시험 장비는 G1628-04 / Ryzen AI 9 HX 370입니다. -L 모델은 공개 프로토콜상 매핑된 기기이며 실물 시험을 하지 않았습니다. 지원하지 않는 모델이나 BIOS에서는 모니터링만 허용합니다. BIOS 버전 문자열이 다르면 수동 제어가 제한됩니다.

2. 바탕화면 구성

  • Pocket Quiet.lnk: 프로그램을 실행하는 바로가기.
  • Pocket Quiet 폴더: 실행 파일, 런타임, 서비스 배포 파일, 문서, 설치·복구 스크립트.
  • PocketQuiet.exe: 설정 화면과 트레이 앱. DLL 등 같은 폴더의 파일이 필요하므로 이것만 옮기지 마세요.
  • 사용설명서.html / 개발명세서.html: 브라우저에서 바로 읽는 문서. 인터넷 연결 없이 열립니다.
  • Install.cmd: 관리자 권한으로 드라이버·서비스 설치.
  • Recover.cmd: 서비스를 멈추고 기기 기본 자동으로 복귀 시도.
  • Uninstall.cmd: 서비스와 설치된 서비스 파일 삭제.
  • source: 해당 배포판의 소스와 빌드 자료.

서비스는 C:\Program Files\Pocket Quiet에서 실행됩니다. 설정과 기록은 C:\ProgramData\PocketQuiet에 있습니다. 바탕화면 앱을 지워도 이미 설치한 서비스는 없어지지 않습니다. 삭제하려면 먼저 제거 스크립트를 실행하세요.

3. 최초 설치와 실행

  1. ZIP을 신뢰할 수 있는 배포처에서 받고 전체를 압축 해제합니다.
  2. FanControl, MotionAssistant, HandheldCompanion, GPDTool 등 기존 팬 제어 프로그램을 종료합니다. 키보드 전용 GPD 도구는 충돌 목록에 포함하지 않습니다.
  3. Install.cmd를 실행합니다. Windows 관리자 권한 요청에 동의합니다. 설치 스크립트는 PawnIO가 없을 때 동봉된 공식 설치 파일의 서명을 검사한 뒤 설치합니다.
  4. 바탕화면 바로가기를 실행합니다. 현재 버전의 설정 화면도 관리자 권한이 필요합니다.
  5. 화면 오른쪽 위가 연결됨인지 확인합니다. 온도와 RPM이 정상 숫자로 나타나야 합니다.
  6. 처음에는 기기 기본 자동입니다. 사용할 프리셋을 선택하고 프리셋 적용을 누릅니다. 선택만 하고 적용하지 않으면 실제 모드는 바뀌지 않습니다.

서비스는 Windows 시작 시 실행되지만, 부팅·서비스 재시작 후 수동 프리셋을 자동으로 재적용하지 않습니다. 설정한 곡선과 선호도는 저장되며, 사용자가 프리셋을 다시 적용합니다. 이 정책은 갑작스러운 종료 후 저속 설정이 무조건 복원되는 것을 방지합니다.

5. 프리셋

기기 기본 자동

팬 출력 레지스터에 자동 제어 값을 기록하고 펌웨어가 팬을 조절하도록 합니다. 이 상태에서는 앱의 온도 곡선이나 선호도가 적용되지 않습니다. 새 설정을 시험하기 전의 기준 상태이며, 언제든 기기 기본 자동으로 복귀 버튼으로 선택할 수 있습니다.

AI 자동 · 적응형

현재 온도, 최근 온도의 평균, 직전 측정 대비 상승 속도를 사용합니다. 빠르게 더워지면 제어에 사용하는 온도를 높여 팬 증가를 앞당깁니다. 식을 때는 기다렸다가 천천히 줄입니다.

이름의 AI는 로컬 규칙 기반 적응형 제어를 뜻합니다. 학습 모델, 외부 AI API, 인터넷 연결, 사용자의 문서나 작업 내용 분석은 사용하지 않습니다. 지속적인 학습 기록도 저장하지 않습니다.

더 조용하게 ↔ 더 시원하게 슬라이더는 제어 온도를 최대 ±5°C 보정합니다. 왼쪽으로 이동해도 최소 출력·고온 보호·오류 대응은 유지됩니다. 슬라이더 변경 후 프리셋 적용을 눌러야 반영됩니다.

저소음 / 균형 / 냉각 우선

온도 저소음 균형 / AI 기본

냉각 우선은 35°C/45%, 50°C/60%, 65°C/75%, 75°C/90%, 85°C/100%를 사용합니다. 중간 온도에서는 직선 보간합니다. 실제 출력에는 상승·하강 속도 제한과 보호 규칙이 추가되므로 표와 매 순간 일치하지 않을 수 있습니다.

사용자 지정

5개 열의 위쪽 칸에 온도, 아래쪽 칸에 출력 백분율을 입력합니다. 온도는 20~85°C에서 엄격하게 증가해야 합니다. 출력은 30~100%이며 오른쪽으로 갈수록 감소하면 안 됩니다. 마지막 점은 반드시 85°C / 100%입니다. 잘못 입력하면 적용이 거부되고 기존 설정이 유지됩니다.

최소 30%는 초기판의 보수적 제한입니다. 팬 정지나 더 낮은 출력은 제공하지 않습니다. 다른 사람의 기기에서 측정한 최저 회전값을 이 기기의 보장값으로 사용하지 마세요.

6. 자동 보호와 복구

  • 1초 주기로 센서를 읽습니다. 평상시 온도는 약 4초 시정수로 완화합니다.
  • 출력이 내려갈 조건이 20초 유지된 뒤 초당 최대 1.5%포인트씩 감속합니다.
  • 평상시 가속은 초당 최대 12%포인트입니다.
  • 현재 온도가 85°C 이상이면 평균과 가속 제한을 건너뛰고 100%를 요청합니다.
  • 80°C 이상은 최소 90%, 75°C 이상은 최소 65%를 목표로 합니다. 이 두 목표에는 평상시 상승 제한이 적용됩니다.
  • 온도 누락·이상치·오래된 시각, RPM 오류가 발생하면 수동 제어를 중단하고 자동 복귀를 시도합니다.
  • 팬 RPM이 연속 2회 0이면 최대 출력으로 회전을 재시도하고, 연속 5회 0이면 오류로 처리합니다.
  • 팬 출력 쓰기 후 읽어 값이 맞는지 검증합니다.
  • 서비스가 정상 종료되면 직접 제어 중이던 팬을 자동으로 돌립니다.
  • 감시 프로세스는 제어 서비스의 신호가 약 8초 끊기면 서비스를 종료시키고 자동 복귀를 시도합니다. Windows 서비스 관리자는 재시작을 수행합니다.

85°C는 이 앱의 냉각 정책값이지 AMD의 최대 허용 온도 표기가 아닙니다. 프로그램은 기기의 기본 열 보호 기능을 해제하지 않습니다. Windows 전체 정지, 커널 드라이버 정지, 하드웨어 고장에서는 소프트웨어 복귀를 보장할 수 없습니다.

7. 창 닫기와 완전 종료

창의 X 또는 트레이로 숨기기는 화면만 숨깁니다. 서비스는 계속 제어합니다. 트레이 아이콘을 두 번 클릭하면 창이 다시 열립니다.

완전히 종료하려면 트레이 메뉴의 자동 복귀 후 종료를 선택합니다. 자동 복귀 확인이 실패하면 오류를 표시하고 종료를 취소합니다. 화면 프로그램을 작업 관리자에서 강제로 종료해도 서비스는 계속 실행됩니다. 강제 종료를 자동 복귀 방법으로 사용하지 마세요.

8. 문제 해결

증상 확인 및 조치
서비스 연결 실패 Install.cmd를 실행하고 관리자 권한으로 앱을 실행. Windows 서비스에서 PocketQuiet 상태 확인
모니터링만 가능 모델·BIOS·센서 준비 조건 확인. 지원 목록을 임의로 바꿔 강제 적용하지 않기
다른 팬 도구 충돌 표시된 프로그램의 팬 제어를 종료한 후 다시 적용
온도가 높고 팬도 시끄러움 실제 발열이 지속되는 상태일 수 있음. 작업 부하·흡배기 조건을 확인하고 냉각 우선 또는 기본 자동 사용
팬 출력이 변경되지 않음 오류 메시지와 기록 확인. 펌웨어나 다른 제어 도구의 개입 가능
앱 또는 드라이버 보안 차단 Windows 보안을 끄지 말고 기본 자동 상태 유지. 드라이버 서명·정책·버전 호환 확인
자동 복귀 실패 Recover.cmd 실행. 복귀 성공 메시지가 없으면 기기 온도·팬 상태를 즉시 확인
로그 폴더 접근 거부 현재 버전의 기록 폴더는 관리자와 SYSTEM만 접근 가능

복구 스크립트는 서비스를 중지한 뒤 자동 제어값을 쓰고 다시 읽어 확인합니다. 실행 후 서비스는 중지 상태로 남습니다. 다시 사용하려면 Install.cmd를 실행하거나 관리자로 서비스를 시작하세요.

9. 기록·개인정보·삭제

설정은 settings.json, 측정값은 telemetry-YYYY-MM-DD.csv, 오류는 errors.log에 저장합니다. 시간은 UTC입니다. CSV는 온도·RPM·출력·CPU 부하·전력·모드를 담습니다. 일일 측정 파일은 약 20MB로 제한하며 14일보다 오래된 측정 파일을 정리합니다. 오류 파일은 약 2MB에서 이전 파일 하나로 회전합니다.

앱은 기록을 서버로 보내지 않습니다. 문제 보고 시 전체 로그 대신 필요한 부분만 확인해 공유하세요. 프로세스 이름 등의 오류 문구가 들어갈 수 있습니다.

Uninstall.cmd는 서비스를 중지·삭제하고 Program Files의 서비스 파일과 바탕화면 바로가기를 제거합니다. 사용자 기록, 바탕화면 배포 폴더, 다른 앱도 사용할 수 있는 PawnIO는 남깁니다. 필요하면 따로 삭제하세요. PawnIO 제거는 다른 하드웨어 모니터링 도구에 영향을 줄 수 있습니다.

10. 검증 범위

이 배포판은 단일 실제 장비에서 센서 읽기, 팬 출력 변경, 자동 복귀, 서비스 적용·초기화·오류 거부, 비정상 종료 복구를 시험했습니다. 장시간 고부하, 실제 절전·최대 절전·복귀, 모든 Windows 보안 정책과 다른 BIOS는 아직 포괄적으로 시험하지 않았습니다. 자세한 결과는 개발명세서와 VALIDATION.md를 확인하세요.
